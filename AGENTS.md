This is a single page application without any server component. All game rule data is stored as constants in the client source code. All runtime data is stored in client local storage. Hosted with GitHub Pages.

## Arbeitsweise und Fortsetzung

- Nutzerpräferenz vom 12.09.2026: Nach jedem abgeschlossenen Arbeitsschritt den logisch nächsten Schritt konkret vorschlagen. Ein Vorschlag allein ist kein Auftrag zur Ausführung.
- Das Übergabedokument als Protokoll führen: neue Einträge oben, ältere unverändert als Historie behalten. Nach jedem abgeschlossenen Arbeitsschritt einen neuen vollständigen GELÖST-Eintrag mit allen weiterhin geltenden Entscheidungen, Umsetzungs-/Prüfstand, offenen Aufgaben und nächstem Schritt voranstellen. Laufende Arbeit als OFFEN oder IN ARBEIT ergänzen. Keine fortsetzungsrelevanten Informationen ausschließlich in der Historie belassen.
- Für die NPC-Arbeit zuerst `src/addins/npc/docs/Uebergabe.md` von oben bis einschließlich des ersten vollständigen GELÖST-Eintrags lesen, dann am LESESTOPP aufhören. Ältere Historie muss nicht gelesen werden, kann bei konkretem Bedarf aber nachgeschlagen werden. Neuere Einträge haben Vorrang; Fachunterlagen sind verlinkt.
